# YAWTIK Studio Portfolio

Portafolio comercial estático de YAWTIK con enfoque en branding, estrategia digital y resultados de campañas publicitarias.

## Publicación

El repositorio incluye un workflow de GitHub Pages en `.github/workflows/deploy.yml`.

Cuando se hace `push` a `main`, GitHub Actions publica automáticamente el sitio.
